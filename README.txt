QUARTZ WEB SOLUTIONS — STANDALONE APPAREL DESIGNER (v6)

SETUP
Extract the ZIP and open Standalone-Apparel-Designer/index.html, or deploy the contents of that folder to a static host such as Cloudflare Pages. No build step, backend, credentials or API keys are needed.

DESIGN
White background with neutral grey and purposeful dark-magenta highlights. The top-left "Quartz Web Solutions" label links to https://quartzwebsolutions.com/. The website has no extra shop pages or navigation header. Layout is responsive for desktop, tablet and mobile.

FEATURES
Choose T-shirt, Polo or Sportswear; design front/back/sleeves; add, move and resize text or pictures; choose garment colour, fabric quality, printing option, size and quantity; download a 1024x1024 PNG of the coloured garment and artwork. Shirt colour is rendered from source photo pixels, keeping folds and texture. Ten text fonts: Anton, Bebas Neue, Oswald, Montserrat, Poppins, Playfair Display, Pacifico, Lobster, Permanent Marker and Orbitron.

IMPORTANT
The ten styles are loaded from Google Fonts and require internet access for their distinctive appearances. Browser fallbacks are available offline. No font files are bundled. Designs and selections are saved locally in the browser. Add to Cart and Buy Now show confirmation animations only; they do not place real orders or collect payments. This website is not connected to One-Line.
